# Refúgio Dellarosa

Landing page institucional do Refúgio Dellarosa — chalés em Itapema, SC.

## Stack

- Next.js (App Router)
- TypeScript
- CSS global com tokens da identidade visual

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run start` — servir build
- `npm run lint` — ESLint

## Conteúdo

Textos, links e mapeamento de imagens ficam em `src/content/site.ts`.
O glossário de domínio está em `CONTEXT.md`.
